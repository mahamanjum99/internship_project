# KTML Internship Project

Internship project repository  Week 1: Foundation, Environment & Database Setup.

## 📋 Overview

This repository documents the setup and initial work completed during Week 1 of the internship, covering Python environment setup, Git version control, Oracle Database configuration, and core Python library practice with database integration.

## 🛠️ Tech Stack

- **Language:** Python 3.11
- **Database:** Oracle AI Database 26ai (Free Edition)
- **DB Connector:** `python-oracledb` (thin mode)
- **Core Libraries:** NumPy, Pandas, OpenCV, Matplotlib
- **Environment:** Python `venv`
- **IDE:** Visual Studio Code + Jupyter
- **Version Control:** Git + GitHub

## ✅ Week 1 Progress

### Day 1 — Environment Setup
- Python virtual environment (`venv`) created and activated
- VSCode connected to `venv` interpreter with working Jupyter kernel
- GPU/CUDA check performed (no NVIDIA GPU available — CPU-only setup)
- Core libraries installed: `numpy`, `pandas`, `opencv-python`, `matplotlib`

### Day 1-2 — Git Workflow
- Repository initialized and connected to GitHub
- `.gitignore` configured to exclude `venv/` and cache files

### Day 2-3 — Database Setup
- Oracle AI Database 26ai (Free Edition) installed locally
- Dedicated schema/user (`maham_intern`) created with appropriate privileges
- Database connection verified via SQL*Plus

### Day 3-4 — SQL Fundamentals
- Tables created using `VARCHAR2`, `NUMBER`, `DATE`/`SYSTIMESTAMP` data types
- Auto-incrementing primary keys via `GENERATED ALWAYS AS IDENTITY`
- Foreign key relationships and `JOIN` queries implemented
- Indexing applied for query optimization
- Connected via `python-oracledb` (thin mode — no Oracle Instant Client required)
- All queries use **bind variables** (no string-formatted SQL, per security best practice)

- Pandas: DataFrame creation and aggregation
- OpenCV: image I/O (create, save, load, pixel analysis)

## 🚀 Setup Instructions

```bash
# Clone the repository
git clone https://github.com/mahamanjum99/internship_project.git
cd internship_project

# Create and activate virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # macOS/Linux

# Install dependencies
pip install -r requirements.txt
```

**Database:** Requires a local Oracle Database instance (Oracle AI Database 26ai Free or compatible) running on `localhost:1521`, with a user matching the credentials used in `db_test.py` / `core_refresh.py`.

## 📌 Notes

- Database credentials in scripts are for local development only and should not be used as-is in production.
- No NVIDIA GPU was available during setup; all work was done in a CPU-only environment.
